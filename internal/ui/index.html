What works in this build

Reframing, timed subtitles, selected local B-roll, basic callout graphics, zoom, and local MP4 rendering. Other advanced toggles are saved as preferences but do not yet add effects. See README for the implementation roadmap.

Use your existing subscriptions

ChatGPT sign-in uses OpenAI’s official open-source application authorization. Claude Code uses Anthropic’s own subscription login. API-key options remain available but use separate API billing. Cloud AI receives candidate transcript excerpts, never your podcast video.
